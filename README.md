# Bambi Cleaning homepage

Static homepage for Bambi Cleaning (Ann Arbor and Metro Detroit), served with GitHub Pages.

- `index.html`: the whole page (HTML, CSS and a small script, no build step)
- `assets/`: logo, photos (WebP) and the service-area map

Hero photos are from Unsplash (free licence). The map is © OpenStreetMap contributors.
Booking buttons link to the live booking pages on bambicleaning.com.
